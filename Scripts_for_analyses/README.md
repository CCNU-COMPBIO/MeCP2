# Scripts for analyses

This directory contains the custom scripts used for selected computational analyses performed in this study.

The scripts are organized into four major components:

1. ClinVar data extraction and curation
2. SASA calculation and structural classification of MeCP2 MBD residues
3. Molecular dynamics trajectory clustering
4. Virtual screening and docking-data processing

Only scripts directly used to generate or process the results reported in this study are included.
