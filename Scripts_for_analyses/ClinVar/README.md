# ClinVar data processing

This directory contains the scripts used to extract and curate MECP2 missense-variant data from ClinVar.

Variant annotation was based on the reference transcript NM_004992.4 and protein sequence NP_004983.1.

The scripts were used to identify germline missense SNVs, verify transcript- and protein-level HGVS annotations, extract Rett syndrome-associated RCV records, and organize the resulting protein-level variant dataset.
