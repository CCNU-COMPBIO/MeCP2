# Topology and coordinate files

This directory contains the AMBER topology and coordinate files used for the ligand-free MeCP2–DNA MD simulations.

The following systems are included:

- WT
- R106G
- R106L
- R106W
- R111G
- R133C
- R133G
- R133L
- E143K

For each system, the corresponding `.prmtop`, `.inpcrd`, and PDB structure files are provided.

The same topology and initial coordinate files were used for the three independent production runs (`run1`, `run2`, and `run3`) of each system.
