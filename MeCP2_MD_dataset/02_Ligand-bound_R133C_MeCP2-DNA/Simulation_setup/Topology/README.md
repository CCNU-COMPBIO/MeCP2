# Topology and coordinate files

This directory contains the AMBER topology, coordinate, and ligand-parameter files used for the ligand-bound Arg133Cys MeCP2–DNA MD simulations.

The following systems are included:

- R133C_DB00266
- R133C_DB00445
- R133C_DB00694
- R133C_DB06237
- R133C_DB08794

For each system, the corresponding `.prmtop`, `.inpcrd`, and PDB structure files are provided.

Ligand parameter files generated using GAFF2 and AM1-BCC are also included where applicable, including `.mol2` and `.frcmod` files.

The same topology and initial coordinate files were used for the three independent production runs (`run1`, `run2`, and `run3`) of each system.
