# ClinVar MECP2 variant data

This directory contains the curated MECP2 missense-variant data derived from ClinVar and used in this study.

Variant annotation was based on the MeCP2-e2 reference transcript NM_004992.4 and protein sequence NP_004983.1.

The deposited data include:

- ClinVar Variation IDs
- Transcript- and protein-level HGVS annotations
- Rett syndrome-associated RCV information
- Clinical significance classifications
- Protein-level missense variants
- MeCP2 domain annotations
- Variant counts used for downstream analyses

Only germline single-nucleotide variants annotated as missense variants were included in the curation workflow.

Multiple nucleotide variants resulting in the same amino-acid substitution were collapsed into a single protein-level variant while retaining the corresponding ClinVar identifiers.

These data were used for the ClinVar-based variant distribution and subsequent MeCP2 MBD analyses.
