# Energy-prediction data

This directory contains the computational predictions of mutation-induced changes in MeCP2 MBD folding stability and MeCP2–DNA binding energetics.

Protein folding stability changes were predicted using GeoStab.

Protein–DNA binding-energy changes were predicted using SAMPDI-3Dv2, PremPDI, and mCSM-NA across compatible experimentally resolved MeCP2 MBD–DNA structures.
