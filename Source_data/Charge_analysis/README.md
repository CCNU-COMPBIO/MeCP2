# Charge-transition analysis data

This directory contains the data used to characterize amino-acid charge changes associated with MeCP2 MBD missense variants.

Amino-acid charge states were assigned as follows:

- Arginine (Arg) and lysine (Lys): +1
- Aspartate (Asp) and glutamate (Glu): -1
- Histidine (His) and all other amino acids: 0

Each missense variant was classified into one of the following charge-transition categories:

- Unchanged
- Positive-charge loss
- Positive-charge gain
- Negative-charge loss
- Negative-charge gain
- Charge reversal

The deposited data include the original and substituted amino acids, assigned charge states, charge-transition categories, and corresponding structural classifications.

These data were used to examine the distribution of charge alterations across protein-interior, protein-surface, and protein–DNA interface variants.
