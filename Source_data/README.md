# Source data

This directory contains the source data underlying the figures and analyses presented in this study, excluding molecular dynamics analysis data that are provided separately in the `MeCP2_MD_dataset` directory.

The deposited source data include:

- ClinVar-derived MECP2 missense-variant data
- Structural classification and SASA-derived data
- Charge-transition data
- Protein folding and protein–DNA binding energy prediction results
- Experimental and predicted ΔΔG comparison data
- Molecular-docking and virtual-screening results
- Other data used to generate the main and supplementary figures

Molecular dynamics analysis data, including RMSD, RMSF, hydrogen-bond, and MM/GBSA results, are provided separately in the `MeCP2_MD_dataset` directory.
